# Royal Spin — Telegram-бот + мини-апп (казино на виртуальных фишках) + админ-панель

## Версия 2 (обновление)
Игры: слоты, монетка, кости, рулетка, краш, дуэли с друзьями (кости, старшая карта, камень-ножницы-бумага).
Разделы приложения: Игры · Друзья · Топ · Профиль (аватар, ник, уровень, промокод).
Админ-панель: дашборд по играм, поиск игроков, переключатели игр, промокоды, выдача фишек всем, рассылка, настройки.
Как обновить уже запущенный проект: в репозитории GitHub нажми Add file → Upload files, перетащи содержимое папки (api, lib, public и файлы) и нажми Commit changes. Vercel пересоберёт сайт сам. Игроки, балансы и настройки в базе не пропадут.

## Что внутри
- `api/bot.js` — бот: на /start присылает приветствие и кнопку «Открыть приложение»
- `public/index.html` — мини-апп: слоты, монетка, топ игроков, ежедневный бонус
- `public/admin.html` — админ-панель (`/admin`): логин и пароль, статистика, игроки, настройки, рассылка
- `api/game.js`, `api/admin.js` — серверная логика (все выигрыши считаются на сервере)

## Запуск за 7 шагов
1. В Telegram откройте @BotFather → `/newbot` → получите **токен**.
2. Загрузите эту папку на GitHub (новый репозиторий), либо в папке выполните `npx vercel`.
3. На vercel.com: Add New → Project → выберите репозиторий → Deploy.
4. В проекте: **Storage → Create/Connect → Upstash Redis** (бесплатный тариф). Переменные базы добавятся сами.
5. **Settings → Environment Variables**, добавьте: `BOT_TOKEN`, `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `WEBHOOK_SECRET` (см. `.env.example`).
6. **Deployments → Redeploy**, затем откройте в браузере:
   `https://ВАШ-ПРОЕКТ.vercel.app/api/setup?key=ВАШ_ADMIN_PASSWORD` — бот подключится.
7. Напишите боту `/start`. Админка: `https://ВАШ-ПРОЕКТ.vercel.app/admin`

## Важно
- Игра идёт на виртуальные фишки без вывода денег. Реальные ставки и выплаты требуют лицензии и в большинстве стран запрещены без неё.
- Данные (игроки, баланс) хранятся в Redis; токен бота и пароль админа держите только в переменных окружения.
