# Royal Spin — Telegram-бот + мини-апп (казино на виртуальных фишках) + админ-панель

## Версия 24 (режимы игр с другом и расчёт ставок)
- Во всех онлайн-играх с другом можно выбрать **дуэль** или **команду против бота**. Командный режим добавлен в шашки, «Четыре в ряд», «Дурака», кости, карты и «Камень, ножницы, бумага»; совместные «Мины» и «Блок Бласт» остаются командными играми.
- Ставка каждого участника одинакова и оплачивается виртуальными фишками. В дуэли победитель получает весь банк (две ставки), проигравший теряет ставку; ничья возвращает обе ставки. В команде победа возвращает каждому игроку 2× его ставки, поражение команды не возвращает ставки. Комиссии с этих игр нет.
- Сдаться можно во время активной партии — это считается поражением. Навигация приложения и системная кнопка «Назад» блокируются до конца онлайн-матча; незавершённую игру можно покинуть только сдачей. Выплаты и результат партии фиксируются одной атомарной операцией и защищены от повторного расчёта.
- В одиночном «Блок Бласте» чаще появляются более крупные фигуры, но набор остаётся проходимым. В «Плинко» шар проходит по реальным колышкам и заканчивает движение в слоте рассчитанного сервером результата. Кнопки игры увеличены для удобного нажатия.
- Проверка изменений: `npm test`.

## Версия 21 (Блок Бласт: огромный квадрат и лаги)
- **Причина огромного квадрата:** в старом CSS игры «Монетка» (v3.css) есть класс `.c3{width:130px;height:130px}`, а зелёные блоки Блок Бласта тоже назывались `c3`. Каждая зелёная клетка раздувалась до 130×130. Клетки переименованы в `bc1..bc6`. Заодно переименованы общие классы в шашках (`.sc`, `.pc` и др.), которые тоже пересекались со старыми стилями (`.sc{width:64px}`).
- **Лаги:** фигура ставится на поле мгновенно, не дожидаясь ответа сервера (при ошибке откатывается); перетаскиваемая фигура двигается через transform без filter и scale; в полноэкранном Блок Бласте отключены фоновые анимации и размытие; добавлены защита от «залипшей» фигуры и подавление подсветки при касании на iOS.

## Что внутри
- `api/bot.js` — бот: на /start присылает приветствие и кнопку «Открыть приложение»
- `public/index.html` — мини-апп: слоты, монетка, топ игроков, ежедневный бонус
- `public/admin.html` — админ-панель (`/admin`): логин и пароль, статистика, игроки, настройки, рассылка
- `api/game.js`, `api/admin.js` — серверная логика (все выигрыши считаются на сервере)

## Запуск за 7 шагов
1. В Telegram откройте @BotFather → `/newbot` → получите **токен**.
2. Загрузите эту папку на GitHub (новый репозиторий), либо в папке выполните `npx vercel`.
3. На vercel.com: Add New → Project → выберите репозиторий → Deploy.
4. В проекте: **Storage → Create/Connect → Upstash Redis** (бесплатный тариф). Переменные базы добавятся сами.
5. **Settings → Environment Variables**, добавьте: `BOT_TOKEN`, `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `WEBHOOK_SECRET` (см. `.env.example`).
6. **Deployments → Redeploy**, затем откройте в браузере:
   `https://ВАШ-ПРОЕКТ.vercel.app/api/setup?key=ВАШ_ADMIN_PASSWORD` — бот подключится.
7. Напишите боту `/start`. Админка: `https://ВАШ-ПРОЕКТ.vercel.app/admin`

## Важно
- Игра идёт на виртуальные фишки без вывода денег. Реальные ставки и выплаты требуют лицензии и в большинстве стран запрещены без неё.
- Данные (игроки, баланс) хранятся в Redis; токен бота и пароль админа держите только в переменных окружения.
